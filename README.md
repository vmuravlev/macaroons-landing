# Macaroons landing

Adaptive landing page with a form and theme switcher (color palette).

## Demo

GitHub Pages: https://vmuravlev.github.io/macaroons-lending/

## Features

- Responsive layout for mobile, tablet, desktop
- Contact/order form with validation
- Separate theme stylesheet to switch color palette
- Smooth animations for sections and buttons

## Tech stack

- HTML5
- CSS3 (flexbox/grid, animations)
- Vanilla JavaScript (form handling, theme switch)

## How to run locally

```bash
git clone https://github.com/vmuravlev/macaroons-lending.git
cd macaroons-lending
# if you use a bundler or dev server:
npm install
npm run dev
# or just open index.html in the browser
